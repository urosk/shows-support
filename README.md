# Shows Support Site

Static support and privacy pages for Shows by Uroš Katić.

- [Support](https://urosk.github.io/shows-support/)
- [Privacy policy](https://urosk.github.io/shows-support/privacy.html)
- [Deployment repository](https://github.com/urosk/shows-support)

GitHub Pages serves the root of `main`. Publish updates with the `github-pages-support` skill.

The preview uses `og.png` and `metal.png` in light mode and `ios-dark.png` and `macos-dark.png` in dark mode. Include all four assets when updating screenshots.
